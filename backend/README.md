HelpDesk TI backend: Spring Boot, Spring Security sessions, Flyway and PostgreSQL. Local development uses H2 with the dev profile. Configure BOOTSTRAP_EMAIL, BOOTSTRAP_PASSWORD (12+ characters), PUBLIC_FRONTEND_URL and FRONTEND_ORIGINS as environment variables. Production requires SPRING_PROFILES_ACTIVE=prod, DATABASE_URL, DATABASE_USER and DATABASE_PASSWORD. Never commit secrets; run Flyway migrations automatically at startup.
